# AYUE ATELIER｜阿月的努努工坊

手作工作室展示站 + 客户约单表单 + 本地订单 ZIP 导出/解析。

## 目前开放服务

1. **来图代缝**：单主提供可用于制作的图纸，工作室手工制作。参考手工费 ¥100 起，常规材料默认包含。
2. **努努一条龙**：包含图纸绘制需求沟通与实体制作。图纸部分参考 ¥30–60（以画师报价为准），制作与增项单独估价。

刺绣面皮、复杂发片等作为上述服务内的制作选项，不是单独的接单类别。

## 访问 / 部署

- 网页无需构建：直接打开 `index.html` 即可预览；GitHub Pages 使用仓库根目录的静态文件。
- 完成订单后下载 ZIP，通过 QQ / 微信发送给阿月。下载或发送本身**不代表接单成功**。
- 订单解析入口 `#parser` 支持导入 ZIP/JSON，可读回图片及制作清单。
- 多只努努分别填写人物正面、人物背面及其他参考，独立增项与色号，提供草稿保存、日夜间模式与手机端适配。

## 修改方式

- `js/config.js`：接单状态、联系账号、增项价格、规则、FAQ、作品集。
- `assets/works/`：放入获得展示许可的作品图，将 `config.js` 中对应的示意插画替换。
- `css/style.css`：主题样式，日间奶油白 / 雾紫 / 浅玫瑰，夜间深紫灰。
- `js/swatches.js`：编号 1–210 色卡的屏幕近似值（不要作为生产染色标准）。
- `assets/fabric-charts/`：五张实拍色卡；可用实物修订时替换。
- `js/app.js`：多步骤表单、ZIP 导出/解析器。历史 V1.1 图纸、刺绣脸独立订单仍可导入解析器，但新订单只开放两种服务。

## 网站性质

纯静态、无服务器收单。上传图纸不会主动上传到网站，所有资料由客户浏览器打包下载，客户自行发送。公开网站的「订单解析」页面不会自动接收或存储其他客户的资料。建议发布前补充真实 QQ / 微信及确认过的作品展示素材。
