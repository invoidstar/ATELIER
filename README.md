# AYUE ATELIER · 阿月的努努工坊（V1.4）

纯静态、无后台的个人手作网站。可直接打开 `index.html`，也可通过 GitHub Pages 部署。

## 网站模块

- 作品集：`assets/works/` 内的 9 张实际手作照片；首页和各类别支持点击大图。来源于工作室提供的作品素材；公开展示原始设计图纸前，应核验相关授权。
- 接单：仅开放「来图代缝」「努努一条龙」两项，可一次填多只努努。联系渠道只选 QQ/微信、闲鱼或画加之一，填写对应账号；每只角色所属 IP 必填（原创设定可填写「原创 OC」）。
- 工艺：兽耳款式一 +¥10/对、款式二 +¥14/对，可看实拍示例；前发片超过 3 层每层 +¥2；头发布料默认 1mm 水晶超柔；色卡仅供头发编号选择。
- 付款：微信/QQ 后付或闲鱼全款链接，以沟通确认为准；网站不会直接收款。
- 排单：常规制作与提前排/加塞均为排到后 15 天内，加塞仅提前排队不缩短工期；加急与超急仍按原规则。
- 导出：浏览器在本地生成 ZIP，含 `order.json`、摘要和上传参考图。可在「订单解析」页面读回。

## 自定义配置

编辑 `js/config.js`：

- `status`：当前档期，可为 `open / queued / closed`。
- `contact`：网站底部联系方式；尚未填写时不显示虚构账号。
- `works`：作品目录，图片文件存放于 `assets/works/`。
- `pricing`：基础工费、兽耳增项、前发片费用、排单倍率等。
- `rules/faq`：约单规则与常见问题。

编辑规则和配色后可以直接刷新本地网页。GitHub Pages 会随 `main` 相关文件更新自动重新部署。

## 文件与隐私

单主上传的图片只在浏览器本地处理；导出后由单主自行联系工作室发送 ZIP。草稿存储在当前浏览器（localStorage / IndexedDB，可受无痕模式及存储权限影响），不保证跨设备同步。订单解析兼容原有 `nunu.order.v1` 格式，并兼容旧版 QQ / 其他联系方式字段。

照片仅供展示，实际材料、颜色、图纸版权及制作可行性需另外确认。
